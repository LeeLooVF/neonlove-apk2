# NeonLove Live - Projet Android Natif (APK automatique via GitHub Actions)

## Instructions :
1. Décompresse ce ZIP sur ton PC. Tu y trouveras le dossier `.github` (avec `workflows/build-apk.yml`) et le dossier `app` complet.
2. Glisse et dépose TOUT ce contenu directement à la racine de ton dépôt GitHub `neonlove-apk`.
3. Va dans l'onglet **Actions** de ton dépôt : le build se lancera automatiquement et te générera ton fichier `app-debug.apk` !
